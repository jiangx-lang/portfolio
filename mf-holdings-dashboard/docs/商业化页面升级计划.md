# ATLAS Market Portfolio · 商业化页面升级计划

> 目标：把当前「数据展示后台」升级为「让人愿意付费的专业投研 SaaS」——视觉更高级、文案更值钱、转化路径清晰、付费墙可落地。

---

## 一、现状诊断（一句话）

项目已具备全资产数据层、AI 摘要层、内容层与分析层，但页面表达仍然偏向「内部工具/数据看板」：

- 首页是入口选择器，没有品牌叙事与付费动机。
- 免责声明过度前置，削弱了专业锐度。
- 缺少 Pricing、会员分级、试用 CTA、付费墙。
- 视觉精致度不足：硬编码色值多、动效简单、部分组件信息过载。
- 美股/期权仍为 mock 数据，严重降低付费可信度。

---

## 二、商业化升级目标

1. **品牌感**：让用户第一眼觉得是「机构级投研工作台」，而不是个人小工具。
2. **价值感**：每页都讲清楚「解决什么问题、为谁省时间、为什么值这个价」。
3. **付费转化**：建立 `Free → Pro → Institution` 三级漏斗，关键功能按权限解锁。
4. **画面精美**：统一暗色金融终端美学，加入玻璃拟态、微光渐变、细腻动效、专业图表。
5. **数据可信**：逐步用真实行情/持仓替换 mock，并在 UI 中明确标注数据来源与更新时间。

## 三、品牌与叙事升级

### 3.1 定位重塑

  2. AI 每天自动汇总个股、基金、组合与市场信号。
  3. 期权策略、宏观风险、再平衡提醒一站掌握。

- 从每页首屏/正文移除大段"不构成任何投资建议"，改为：

  - 注册/订阅流程中一次性确认《服务条款与风险揭示》。

## 四、视觉设计系统升级

### 4.1 色彩体系（Premium Dark）

在现有 `#0a0e1a` 深色基础上，引入更丰富的金融高级感色板：

| 用途 | 当前 | 升级后 |
|---|---|---|
| 主背景 | `#0a0e1a` | `#070A12`（更深邃）+ 径向渐变光晕 `#0B1426` |
| 卡片背景 | `#111827` / `#0d1b2e` | `rgba(17,24,39,0.72)` + backdrop-blur 玻璃感 |
| 主强调色 | `#185FA5` | 渐变 `linear-gradient(135deg, #185FA5, #3B82F6)` |
| 高级金 | 无 | `#C9A84C` 用于 Pro/Institution 徽章、价格、关键数值 |
| 涨跌 | `#1D9E75` / `#D85A30` | 增加饱和度与发光效果 |
| 边框 | `rgba(255,255,255,0.07)` | `rgba(255,255,255,0.08)` + hover 时淡蓝光 |

- 所有颜色收敛到 `tailwind.config.ts`，移除硬编码色值。
- 新增 `premium-glow`、`glass-card`、`gold-accent` 等 Tailwind 工具类。

### 4.2 字体与排版

- 英文标题：引入 `Inter` / `Plus Jakarta Sans`（已在用 Inter）。
- 中文标题：使用 `"PingFang SC"`、`"Noto Sans SC"`，字重 600-700。
- 数字：等宽字体 `IBM Plex Mono` 或 `JetBrains Mono`，增强金融终端感。
- 字号层级：
  - Hero 标题：`text-4xl md:text-5xl lg:text-6xl`，行高 1.1。
  - 页面标题：`text-2xl md:text-3xl`。
  - 卡片标题：`text-lg font-semibold`。
  - 辅助说明：`text-sm text-slate-400`。

### 4.3 组件质感

- **卡片**：统一 `rounded-2xl`、玻璃背景、1px 边框、hover 时 `translateY(-2px)` + 边框高亮 + 阴影扩散。
- **按钮**：
  - Primary：蓝渐变 + 白色文字 + hover 光晕。
  - Premium/Gold：金边框 + 金色文字，用于 Pro 解锁、订阅 CTA。
  - Ghost：透明 + 细边框，用于次要操作。
- **Badge/Tag**：更精致的小药丸，带图标，如 `🔒 Pro`、`✨ AI 生成`、`🕒 实时`。
- **图表**：
  - 净值曲线：渐变填充 + 发光描边。
  - 饼图/环形图：金色/蓝色强调，hover 放大。
  - 增加图表空状态/骨架屏。

### 4.4 动效与交互

- 页面入场：内容区 `fade-in + translateY(16px)`，stagger 100ms。
- 数字滚动：关键指标（AUM、收益、风险评分）首次进入视口时数字递增。
- Hover：卡片上浮、按钮光晕、表格行高亮。
- 加载：全局骨架屏 + 脉冲 shimmer，替代简单 spinner。
- Toast/Modal：滑入 + 背景模糊。

## 五、会员体系与付费转化

### 5.1 三级会员

| 等级 | 权限 | 价格锚点 |
|---|---|---|
| **Free** | 浏览基础基金池、看 3 篇最新笔记/播客、每日 1 次 AI 摘要 | 免费 |
| **Pro** | 无限 AI 摘要、持仓深度分析、Risk 仪表板、历史报告、自选组合、净值预警 | ¥68/月 或 ¥588/年 |
| **Institution** | API 数据导出、白标报告、B2B WMP 面板、多席位、专属客服 | 联系销售 |

### 5.2 新增页面与功能

- **`/pricing`**：三列价格卡片，突出 Pro；包含 FAQ、对比表、年付折扣。
- **`/account`**：订阅管理、使用配额、账单历史、API Key（机构）。
- **权限中间件**：在 `middleware.ts` 增加 `role: free | pro | institution`，路由级权限控制。
- **付费墙组件**：`PaywallCard` —— 模糊锁定内容 + "升级 Pro 解锁" CTA。
- **使用计数**：AI 生成、深度报告、历史数据请求均计数，接近配额时提示升级。
- **试用机制**：Pro 7 天免费试用，绑定支付后启用。

### 5.3 转化触点

| 页面 | 转化动作 |
|---|---|
| Landing | Hero 区 "免费试用 Pro" / "查看方案" |
| QD/MRF | AI 摘要按钮旁显示 "今日剩余 N 次" |
| Stock | 期权链/策略卡加 "Pro 实时数据" 标签 |
| Risk | 整页 Paywall，预览 3 张指标卡 |
| Notes/Podcast | 第 4 篇起模糊并提示订阅 |
| 深度分析 | "生成一页纸报告" 前弹试用窗口 |

## 十、实施路线图

### Phase 1：基础商业化（2–3 周）

- [ ] 设计系统升级：`tailwind.config.ts` + `globals.css` + 通用组件。
- [ ] 新增 `/pricing` 页面。
- [ ] 会员中间件：`middleware.ts` 增加 role 校验。
- [ ] 用户表/订阅表设计（Supabase 或自建）。
- [ ] 内容付费墙：notes / podcast / risk 前三项免费。
- [ ] AI 配额：Free 每日限制，Pro 无限。

### Phase 2：产品体验升级（4–6 周）

- [ ] 重构首页为 Premium Landing。
- [ ] 预生成 AI 摘要并缓存。
- [ ] 接入真实行情（美股、QDII 净值）。
- [ ] `/signals` 重构为信号中心。
- [ ] `/risk` 重构为交互式仪表板。
- [ ] QD/MRF 增加基金对比、自选、预警。
- [ ] 一页纸 PDF 报告导出。

### Phase 3：高阶订阅与 B2B（2 个月+）

- [ ] Institution 套餐：API、白标报告、多席位。
- [ ] WMP B2B 客户经理面板。
- [ ] 邮件/Slack/企微通知系统。
- [ ] 组合回测、再平衡、税务/汇率成本计算。
- [ ] 支付集成：Stripe / 支付宝 / 微信。
